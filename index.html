About

I build the environments that LLM coding agents train and get graded in. My day job is turning real merged GitHub pull requests into reproducible Docker tasks with hidden tests, then checking that agents actually solve them instead of gaming the grader. I've shipped 2,000+ of these environments and 2,000+ agent trajectories for SFT and RL post-training.

Gauntlet: leak-free RL environments from fresh GitHub PRs

My main open source project. It mines PRs merged after a model's training cutoff, rebuilds each repo at the base commit in Docker, and grades agents the way SWE-bench style benchmarks do. Then it tries hard to cheat its own grader.

  • gauntlet-harness: PR mining, F2P/P2P test classification, a leak scan, rubric judging, a Gymnasium env and exports for SWE-bench, SFT, GRPO and DPO
  • gauntlet-cheatcatcher: reward-hacking detectors for coding agents
  • gauntlet-repo2env: turns a repo into Docker env images and SWE-style tasks
  • gauntlet-sandbox and gauntlet-timemachine: record, replay and diff agent trajectories
  • gauntlet-arena: a FastAPI app where a human and an AI agent race on the same task

Backend work: a policy and claims REST API

policy-claims-api is an insurance back office built with FastAPI, PostgreSQL and Redis. Agents write policies and file claims, assessors decide them, admins see everything.

  • JWT authentication with three roles. A record the caller cannot read returns 404 rather than 403, so the API never confirms that someone else's policy exists, and the role is re-checked against the database row on every request instead of being trusted from the token.
  • The money rules are the point: approved claims cannot add up past the sum insured even when each one is individually valid, a rejection frees its cover again, and a claim cannot be decided twice. Amounts are stored in paise as integers, never floats.
  • Claim filing takes an Idempotency-Key, so a retried request returns the claim it already created and two racing retries resolve to one. Redis caches reads and degrades to a cache miss when it is down rather than failing the request.
  • 35 tests at 93% line coverage, running on SQLite so CI needs no services. GitHub Actions runs ruff, the suite, and a job that builds the image, boots the container and curls the health endpoint.
