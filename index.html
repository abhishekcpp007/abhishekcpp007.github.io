About

I build the environments that LLM coding agents train and get graded in. My day job is turning real merged GitHub pull requests into reproducible Docker tasks with hidden tests, then checking that agents actually solve them instead of gaming the grader. I've shipped 2,000+ of these environments and 2,000+ agent trajectories for SFT and RL post-training.

Outside work I read the source of the eval and interpretability libraries I use, find bugs nobody has reported yet, and send fixes with regression tests. I'm open to AI engineer, LLM evaluation and Python backend roles, remote or with relocation.

Gauntlet: leak-free RL environments from fresh GitHub PRs

My main open source project. It mines PRs merged after a model's training cutoff, rebuilds each repo at the base commit in Docker, and grades agents the way SWE-bench style benchmarks do. Then it tries hard to cheat its own grader.

  • gauntlet-harness: PR mining, F2P/P2P test classification, a leak scan, rubric judging, a Gymnasium env and exports for SWE-bench, SFT, GRPO and DPO
  • gauntlet-cheatcatcher: reward-hacking detectors for coding agents
  • gauntlet-repo2env: turns a repo into Docker env images and SWE-style tasks
  • gauntlet-sandbox and gauntlet-timemachine: record, replay and diff agent trajectories
  • gauntlet-arena: a FastAPI app where a human and an AI agent race on the same task
